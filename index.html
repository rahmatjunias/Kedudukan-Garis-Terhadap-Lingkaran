Kedudukan Garis terhadap Lingkaran

Satu garis bisa tidak menyentuh, menyentuh, atau memotong lingkaran. Pahami perbedaannya lewat visualisasi dan latihan singkat.

Mulai belajar  ↓
01 · Konsep dasar

Tiga kemungkinan, satu kunci

Bayangkan jarak tegak lurus dari pusat lingkaran ke garis. Bandingkan jarak itu dengan jari-jari.

0

Garis di luar lingkaran

Jarak pusat ke garis lebih besar daripada jari-jari. Garis tidak memiliki titik persekutuan dengan lingkaran.

1

Garis menyinggung

Jarak pusat ke garis sama dengan jari-jari. Garis dan lingkaran memiliki tepat satu titik persekutuan.

2

Garis memotong

Jarak pusat ke garis lebih kecil daripada jari-jari. Ada dua titik persekutuan; jika melalui pusat, tali busurnya adalah diameter.

02 · Eksplorasi

Geser garisnya

Ubah jarak garis dari pusat lingkaran dan amati jumlah titik potongnya.

Jarak pusat ke garis

Jari-jari lingkaran tetap r = 5 satuan. Geser garis untuk melihat perubahan kedudukannya.

05 (r)8
Garis memotong lingkaran d < r: terdapat dua titik persekutuan.
03 · Cara analitis

Gunakan rumus jarak titik ke garis

Untuk lingkaran berpusat di O(p, q) dengan jari-jari r, dan garis ax + by + c = 0, hitung jarak tegak lurus dari pusat ke garis.

Setelah itu, bandingkan hasilnya dengan r. Cara ini berlaku meskipun garisnya miring.

d = |ap + bq + c| / √(a² + b²)

d = jarak pusat ke garis · (p, q) = pusat lingkaran · r = jari-jari

Contoh cepat. Pusat lingkaran O(0, 0), r = 5, dan garis 3x + 4y − 25 = 0. Jaraknya d = 25/5 = 5, sehingga garis menyinggung lingkaran.
